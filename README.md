<h2>🚀 Featured Projects</h2>

<h3>📄 IntelliDoc – AI-Powered Document Assistant</h3>

<p>
An intelligent document assistant that uses Retrieval-Augmented Generation (RAG)
to provide context-aware answers from uploaded PDF documents.
</p>

<b>Key Features:</b>

- PDF processing and intelligent text chunking.
- Semantic embeddings using Sentence Transformers.
- FAISS-based vector similarity search.
- Gemini API integration for AI-generated responses.
- AI-powered document summarization.
- Interview question generation.
- AI agent functionality.
- Docker containerization.
- Automated CI/CD using GitHub Actions.

<b>Tech Stack:</b>

Python | Streamlit | FAISS | RAG | Gemini API |
Sentence Transformers | Docker | Pytest | GitHub Actions
